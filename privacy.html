Privacy Policy — Personal Agent

Last updated: 21 September 2026

Personal Agent is a private, self-hosted personal assistant built and operated by Willian Pereira César for his own use. It is not a commercial product, it is not distributed, and it has no users other than its operator. This page exists to describe, honestly and specifically, how the application handles Google user data.

What data the application accesses

The application requests a single Google OAuth scope: https://www.googleapis.com/auth/calendar. It uses this scope to read events from, and create, modify and delete events on, the calendar of the single Google Account that authorises it — the operator's own account.

It does not request access to Gmail, Google Drive, Contacts, Sheets or Docs, and it cannot read them.

How the data is used

Calendar data is used for exactly two purposes:

  • To send the operator reminders about his own upcoming events, through a private Telegram bot that accepts messages only from his own account.
  • To create or reschedule events on his own calendar when he asks for one in that same private chat.

Event text is sent to Anthropic's API for language processing, under Anthropic's own terms, solely to interpret the operator's requests and compose his reminders. No calendar data is used for advertising, profiling, resale, or for training any model.

Where the data is stored

The application runs in a container on a private server rented by the operator. The OAuth token and a small amount of reminder state are stored on that server's disk, readable only by the account the application runs as. No calendar data is stored anywhere else, and none of it is transmitted to any third party other than the two services named above (Google, to read and write the calendar, and Anthropic, to process language).

Sharing

No Google user data is shared with, sold to, or transferred to any third party, under any circumstances.

Retention and deletion

The OAuth token is kept until it is revoked. The operator can revoke the application's access at any time from the Google Account permissions page, which immediately and permanently ends the application's ability to read or write the calendar. Local state is deleted when the container's storage volume is deleted.
